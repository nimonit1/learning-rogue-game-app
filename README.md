# DungeonStudy ⚔️

**ローグライク型・高校受験対策学習ゲーム**

ダンジョンを探索して敵（問題）を倒し、経験値を得てレベルアップする。
**アクティブリコール（能動的想起）** と **SRS（間隔反復）** をゲームシステムに統合した中学3年生向けブラウザアプリ。

- **バージョン**: v1.1.0
- **ターゲット**: 中学3年生（12〜15歳）、高校受験対策
- **プラットフォーム**: スマートフォン優先ブラウザアプリ（PC・タブレット対応）
- **公開**: GitHub Pages（`dungeon_study.html` を開くだけで動作）
- **外部依存**: Google Fonts（Noto Sans JP）のみ

---

## 特徴

| 機能 | 内容 |
|---|---|
| ローグライク探索 | 9×9 アイソメトリックマップ、Recursive Backtracking 生成、霧（フォグオブウォー）あり |
| アクティブリコール | 問題回答前に3秒の想起フェーズ。答えを「思い出す」行為で記憶定着を促進 |
| SRS（間隔反復） | 不正解・タイムオーバーの問題を「呪いリスト」に記録し、次回入場時に再出題 |
| ボス封印システム | 雑魚を全滅させないとボスに挑めない。段階的な学習フロー |
| 記述式ボス問題 | ボスは4択でなく自由テキスト入力。真の定着度を測定 |
| EXP・レベルシステム | Lv.9999 まで成長。称号は14段階 |
| 効果音 | Web Audio API によるチップチューン風SE（移動・正解・不正解・レベルアップ等） |
| レスポンシブ対応 | スマホ・タブレット・PC（600 / 900 / 1200px 対応） |
| マップズーム | dpad右上🔍ボタンで3段階切替（縮小🔭 / 標準🔍 / 拡大🔎）|
| 管理画面 | JSONインポートで問題を追加・編集。AIプロンプト自動生成機能つき |

## ゲームシステム

### 基本フロー

```
タイトル → アバター選択 → ダンジョン選択
  → ダンジョン探索（9×9マップ移動）
    → 敵と遭遇 → 想起フェーズ（3秒）→ 問題回答（20秒）
      → 正解: EXP 獲得 → レベルアップ
      → 不正解 / タイムオーバー: HP 減少 + 呪いリストに追加
    → 雑魚全滅 → ボス解放 → ボス撃破 → クリア
```

### EXP・レベル

| 項目 | 仕様 |
|---|---|
| 次レベル必要EXP | `floor(15 × ln(lv+1) + 10)` |
| Lv1→2 | 20 EXP（雑魚1体で到達） |
| 難易度別EXP | 易:20 / 中:28 / 難:38 / ボス:50 |
| 速攻ボーナス | 制限時間50%以上残り → 満額、超過 → 60% |

### HP 回復（3種類）

| 条件 | 効果 |
|---|---|
| 3連続正解（コンボ） | HP +1 |
| ボス撃破 | HP 全回復 |
| 呪い問題に正解 | 失った分を回復 |

### 称号（14段階）

Lv.1「見習い冒険者」→ Lv.5「新米冒険者」→ Lv.10「一人前の冒険者」→ … → Lv.9999「全知の存在」

## 操作方法

### スマートフォン

- **移動**: 画面下部の方向ボタン（↑↓←→）
- **メニュー**: 中央の ⚔ ボタン
- **ズーム**: 右上の 🔍 ボタン（3段階切替）
- **ミュート**: HUD右端の 🔊 ボタン

| キー | 動作 |
|---|---|
| `↑↓←→` / `WASD` | 移動 |
| `+` / `=` | ズームイン |
| `-` | ズームアウト |

## 問題の追加方法

管理画面（⚙️ 管理ボタン）から JSON 形式でインポートできます。

```json
{
  "name": "ダンジョン名",
  "subject": "科目名",
  "icon": "⚗️",
  "color": "#00809E",
  "questions": [
    {
      "difficulty": 1,
      "monster_name": "ゴブリン",
      "question": "問題文",
      "choices": ["A", "B", "C", "D"],
      "answer": "A",
      "explanation": "解説文"
    },
    {
      "difficulty": 4,
      "type": "boss",
      "monster_name": "ドラゴン",
      "question": "記述式の問題文",
      "answer": "正解",
      "explanation": "解説文"
    }
  ]
}
```

- `difficulty 1〜3`: 4択問題（雑魚）
- `difficulty 4` + `"type":"boss"`: 記述式（ボス、`choices` 不要）
- `monster_name` / `hint` は省略可
- AI が生成した JSON をそのまま貼り付け可能（Markdown コードブロック・全角スペース等を自動除去）

管理画面の **🤖 AIプロンプト** ボタンから、Claude 等の AI に渡すプロンプトを自動生成できます。

## 技術仕様

| 項目 | 内容 |
|---|---|

## 既知の制限

| 項目 | 内容 |
|---|---|
| 呪いリスト非永続化 | ページリロードでリセット（localStorage 未保存） |
| ボス記述式の正答判定 | `trim()` による完全一致のみ。全角・スペースの表記揺れ非対応 |
| localStorage 上限 | 5MB。問題数が数百問規模になると不足 |
| 図鑑非永続化 | 討伐図鑑もページリロードでリセット |
